# 元プロジェクトからの変更点

元のZIPは一切変更していません。統合用の新しいフォルダに複製し、そこで作業しました。元ソース75ファイルのSHA-256を `docs/original-sha256.txt` に記録し、`tests/test-originals.js` が機械的に照合します。

**結果: 75ファイル中 70 はバイト単位で同一。変更は次の5ファイルだけです（差分は `docs/patches/`）。**

| ファイル | 変更 | 目的 |
|---|---|---|
| `engines/code/app.js` | **1行追加**（`window.__ZS_CODE_HOOK__&&…` を初期化の直前に） | IIFE 内部の状態を、ブリッジ（`zs-bridge.js`）が読み書きできるようにする。フックが無ければ何も起きない |
| `engines/code/index.html` | `<script src="zs-bridge.js">` を1行追加 | ブリッジの読み込み |
| `engines/logic/script.js` | **1行置換**（Machine Lab の `return{tab,save,test}` に `zs:{exp,mclean,load,pause}` を追加） | Machine Lab の保存・読込をブリッジから呼べるようにする。既存の戻り値は変更なし |
| `engines/logic/index.html` | `<script src="zs-bridge.js">` を追加 | ブリッジの読み込み |
| `engines/zero/index.html` | `<script src="zs-bridge.js">` を1行追加（+コメント） | 連携ローダーの読み込み（`?zs=1` のときだけ有効） |

**Zero の JavaScript・CSS は1行も変更していません。** 元の ZIP にあった `.github/`（Zero 単体の Pages 用ワークフロー）は、入れ子のフォルダでは動かないため複製に含めていません。

## 元アプリの動作を、ブリッジが外から変えている点（元コードは無変更）

- **Pixel Lab の「JSON読込」**（`#pixelImportInput`）: 元の実装は色の値を検証せず `innerHTML` に入れるため、細工したJSONで HTML 注入が起こり得ました。ブリッジが読み込み前に検証し、`#RGB` 形式の色と許可したキーだけを通します。
- **Logic のヘッダーリンク**: `example.com` を指すプレースホルダー（「CODE-LAB」「ポートフォリオ」）を、前者は ZeroStudio の Code Studio への導線に、後者は非表示にしました（ZeroStudio 内でのみ）。
- **Zero の保存先**: 共通ストアに差し替え（`PZ.storage.open` のみ）。Zero 単体で開くと従来どおりです。

# V1.1 デザイン刷新（ZeroStudio Design System V1）

見た目と操作の統一だけを変更した版です。保存方式・データ形式・エンジン間連携・各エンジンのレイアウトは変更していません。元のエンジンのファイルも1バイトも変えていません。

## 変更点

- **共通デザインシステム**: `css/zs-tokens.css`（ネイビー基調、淡いブルー／ミント、角丸・影・余白・動きのトークン）。シェルと3エンジンが同じ値を参照します。
- **ホーム**: 3エンジンが共通プロジェクトにつながる様子を示すメインビジュアル、新規作成、続きから、エンジン入口、最近のプロジェクト。
- **ナビゲーション**: 1行のトップバー（補助3画面はアイコン）。スマホ幅ではドロワーと下部タブ。制作画面では下部タブを隠して作業領域を確保。
- **新規作成**: どの画面からでも1回の選択で全8種類の作品タイプを作れるダイアログ。
- **プロジェクト一覧**: エンジン色のアイコン、リスト／カード表示（記憶）、検索0件・空状態の案内。
- **保存状態**: 保存済み・保存中・変更あり・エラーを色と文言で表示。
- **ダイアログ・通知・メニュー**: 共通の見た目と動き、スマホ幅ではシート表示。
- **エンジン**: `css/zs-engine-{code,logic,zero}.css` を統合時だけ読み込み、配色を統一し重複する枠（ブランド・状態表示）を整理。単体表示は元のまま。
- **不具合修正**: Code Studio のスマホ幅で「ツール」タブが空になる問題（統合時のみ）。
- **テスト**: `tests/e2e/design.js` を追加。シェルのスマホ操作テストと、エンジンの見た目比較テストを新仕様に更新。

## 既知の制限（V1.1）

- Webフォントは CSP のため使えず、端末の日本語フォントを使います。
- Zero Engine の粒子の色は元の JavaScript で決まっており、新パレットには揃っていません。
- Logic Studio の上部ボタン列は、機能を保つためそのまま残しており、2段になります。
- Code Studio 内の「保存」ボタンは残しているため、シェルの「保存」と並んで見えます。
