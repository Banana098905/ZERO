# 既存機能の維持状況

**維持の根拠**: Zero は JS/CSS が元とバイト単位で同一。Code Lab は `app.js` に1行追加のみ、Logic は `script.js` の1行置換のみ（docs/CHANGES.md）。したがって元の機能は**コードが変わっていません**。
そのうえで、実ブラウザ（Chromium）で統合版の中から動かして確認できたものと、起動・表示の確認にとどまるものを分けて記します。

確認の凡例: **◎** 統合版の中で自動テストが実際に操作・検証 ／ **○** 元コードは無変更で起動・表示は確認、個別操作の自動テストなし

| 機能 | 状況 | 根拠 |
|---|---|---|
| HTML / CSS / JS の3タブ編集、実行、ライブプレビュー | ◎ | テスト C1（JS を書いて実行→プレビュー内の要素を確認） |

| Pixel Lab: 描画データの読み書き、コード生成（CSS 等） | ◎ | C1・C2（元の生成コードと ZeroStudio の変換が一致） |
| Pixel Lab の個別ツール（塗りつぶし・フレーム・アニメ・元に戻す等） | ○ | 無変更。個別の自動テストなし |
| コードの整形・コピー・プレビューのデバイス切替・HTML 書き出し等 | ○ | 無変更。個別の自動テストなし |
