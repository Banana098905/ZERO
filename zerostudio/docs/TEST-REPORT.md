## 開発中に見つけて直した欠陥（テストが検出）

- **ブリッジの変更検知の競合**: 読み込み直後（最初の600ms以内）の編集が基準に吸収され、自動保存されなかった → 基準を起動直後に確定。
- **付随データが復元されなかった**: `getMeta` が「無い」を `null` で返すのに `undefined` と比較していた → 存在確認に変更。Zero のお気に入り・部品などが、バックアップ復元・旧データ移行で欠落していた。
- **作成時に依存関係・素材参照をスキャンしていなかった**: 自動作成直後の機械で、回路への依存が記録されなかった → 作成時にも計算。
- **素材由来の記録が最初の自動保存で消える設計だった**（予防的に修正）。
- **「準備完了」後に iframe を付け直すと再読み込みされる**問題 → 読み込み表示を重ねて外すだけにした。
- **Zero の `dist` ビルド検査が失敗**（`index.html` がフォルダ外を参照していた） → フォルダ内のローダー1本に変更。Zero 単体のテスト55件を回復。
- CSS カスタムプロパティ（エンジンの識別色）が反映されない、`IdbRepo.put` が同期例外を投げ得る、Logic ヘッダーの `example.com` リンク、不安定なテスト1件（検証結果ではなく静的文言を待っていた）。
- 元アプリの **Pixel Lab「JSON読込」の HTML 注入経路**を発見（入口をブリッジで検証）。

## このテストでは確認できていないこと

KNOWN-ISSUES.md の「未検証」を参照してください（Chromium 以外・実機モバイル・各ツールの個別操作・Pages への実デプロイ・大きなデータでの性能・アクセシビリティ監査 など）。**テストが通ったことは、上記の範囲での動作を示すもので、すべての操作の無欠陥を保証するものではありません。**
